# 🛒 Meu E-commerce

Loja virtual desenvolvida com HTML, CSS e JavaScript puro, usando Supabase como backend completo.

## 🚀 Tecnologias

- **Frontend:** HTML5, CSS3, JavaScript (ES Modules)
- **Autenticação:** Supabase Authentication (Google, Email/Senha)
- **Banco de dados:** Cloud Supabase
- **Armazenamento:** Bando de dados Supabase
- **Hospedagem:** Netlify
